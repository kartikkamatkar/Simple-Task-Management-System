📝 Task Management System

A simple and practical Task Management System built using HTML, CSS, JavaScript, Spring Boot, and PostgreSQL.
The project includes user authentication, task CRUD operations, and a clean UI.
The main aim was to build a working full-stack project with proper backend flow and database integration.

🚀 Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Spring Boot, Spring Security
Database: PostgreSQL
Build Tool: Maven

✨ Features
 🔐 User login & registration
 ➕ Add tasks
 ✏️ Update tasks
 ❌ Delete tasks
 ✔️ Mark tasks as completed
 🗄 PostgreSQL database integration
 🔒 Secured backend using Spring Security
 🎨 Clean & simple UI

📡 API Endpoints
 GET /tasks — Fetch all tasks
 POST /tasks — Add a new task
 PUT /tasks/{id} — Update a task
 DELETE /tasks/{id} — Delete a task
